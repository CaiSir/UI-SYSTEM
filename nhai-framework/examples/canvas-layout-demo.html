📐 Canvas布局示例

展示如何使用NHAI布局组件来组织多个Canvas

1️⃣ 垂直布局 (VBoxLayout)

// 垂直排列两个Canvas
const canvas1 = new MaterialCanvas()
canvas1.setCanvasSize(800, 300)
canvas1.setBackground('#e3f2fd')

const canvas2 = new MaterialCanvas()
canvas2.setCanvasSize(800, 300)
canvas2.setBackground('#fff3e0')

const vbox = NHAIObjectFactory.createVBoxLayout()
vbox.addWidget(canvas1)
vbox.addWidget(canvas2)
vbox.setSpacing(10)
vbox.setWidth('100%')
vbox.setHeight(400)

const element = vbox.render()
container.appendChild(element)

3️⃣ 网格布局 (GridLayout)

// 2x2网格布局
const canvas1 = new MaterialCanvas()
canvas1.setCanvasSize(600, 300)
canvas1.setBackground('#f3e5f5')

const canvas2 = new MaterialCanvas()
canvas2.setCanvasSize(600, 300)
canvas2.setBackground('#e0f2f1')

const canvas3 = new MaterialCanvas()
canvas3.setCanvasSize(600, 300)
canvas3.setBackground('#fff8e1')

const canvas4 = new MaterialCanvas()
canvas4.setCanvasSize(600, 300)
canvas4.setBackground('#ffebee')

const grid = NHAIObjectFactory.createGridLayout()
grid.setColumns(2)
grid.addWidget(canvas1)
grid.addWidget(canvas2)
grid.addWidget(canvas3)
grid.addWidget(canvas4)
grid.setSpacing(10)
grid.setWidth('100%')
grid.setHeight(450)

const element = grid.render()
container.appendChild(element)

4️⃣ 分割面板 (SplitPanel)

// 可调整大小的分割面板
const canvas1 = new MaterialCanvas()
canvas1.setCanvasSize(800, 400)
canvas1.setBackground('#e1f5fe')
canvas1.setMode(CanvasMode['2D'])

const canvas2 = new MaterialCanvas()
canvas2.setCanvasSize(800, 400)
canvas2.setBackground('#fff9c4')
canvas2.setMode(CanvasMode['3D'])

const splitPanel = new MaterialSplitPanel()
splitPanel.setOrientation('horizontal')
splitPanel.setSplitPosition(50)
splitPanel.setLeftPanel(canvas1)
splitPanel.setRightPanel(canvas2)
splitPanel.setWidth('100%')
splitPanel.setHeight(400)

const element = splitPanel.render()
container.appendChild(element)

5️⃣ 嵌套布局 (VBox + HBox)

// 嵌套布局：顶部VBox包含HBox + Canvas
const topCanvas = new MaterialCanvas()
topCanvas.setCanvasSize(1600, 200)
topCanvas.setBackground('#f1f8e9')

const bottomHBox = NHAIObjectFactory.createHBoxLayout()

const leftCanvas = new MaterialCanvas()
leftCanvas.setCanvasSize(800, 250)
leftCanvas.setBackground('#fff3e0')

const rightCanvas = new MaterialCanvas()
rightCanvas.setCanvasSize(800, 250)
rightCanvas.setBackground('#e8eaf6')

bottomHBox.addWidget(leftCanvas)
bottomHBox.addWidget(rightCanvas)
bottomHBox.setSpacing(10)

const outerVBox = NHAIObjectFactory.createVBoxLayout()
outerVBox.addWidget(topCanvas)
outerVBox.addWidget(bottomHBox)
outerVBox.setSpacing(10)

const element = outerVBox.render()
container.appendChild(element)
