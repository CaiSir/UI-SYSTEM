第一章：NHAI 框架介绍

NHAI（Next-generation Human-Computer Interaction）框架是一个现代化的UI框架， 旨在提供灵活、高效的组件开发体验。

本框架支持多种前端框架适配，包括 React、Vue、Svelte 和原生 JavaScript， 让开发者可以在不同的技术栈中无缝使用相同的组件。

核心特性

- 命令式 API：简洁直观的组件调用方式 - 多框架适配：一套组件，多端使用 - Material Design：遵循 Material Design 设计规范 - TypeScript 支持：完整的类型定义

第二章：目录栏组件使用

目录栏（Table of Contents）组件用于展示文档或页面的层级结构， 帮助用户快速导航到感兴趣的章节。

基本用法

创建目录栏组件需要定义一个包含标题和层级的数组， 每个项目可以包含子项目，形成树形结构。

高级功能

- 可折叠：支持展开和折叠子节点 - 活动状态：自动高亮当前浏览位置 - 锚点跳转：点击目录项自动滚动到对应内容 - 多种样式：提供默认、边框和紧凑三种样式

第三章：组件 API

本节介绍目录栏组件的主要 API 和使用方法。

创建组件

使用 new MaterialTableOfContents() 创建目录栏实例。

配置选项

- setItems(): 设置目录项 - setVariant(): 设置样式变体 - setSize(): 设置尺寸大小 - setCollapsible(): 设置是否可折叠 - setDefaultExpandAll(): 设置默认展开所有项

第四章：最佳实践

在使用目录栏组件时，有一些最佳实践值得遵循。

内容组织

确保内容的层级结构清晰，避免过深的嵌套层级。 建议控制在 3-4 级以内，以保证良好的用户体验。

交互设计

考虑用户的使用场景，合理设置默认展开状态。 对于较长的文档，默认折叠所有项，让用户按需展开。
