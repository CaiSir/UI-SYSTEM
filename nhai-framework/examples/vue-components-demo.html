🚀 Vue + Element UI 组件示例

基于 NHAIWidget 的命令式 API，使用 Vue + Element UI 实现

基础按钮

📝 代码：
const btn = new VueButton('点击我')
btn.setType(VueButtonType.PRIMARY)
btn.setOnClick(() => alert('Hello!'))
const element = btn.render()
container.appendChild(element)

💡 说明：
- 使用 Vue 3 + Element Plus 作为底层 UI 库
- 仍然保持 NHAIWidget 的命令式 API 风格
- 如果没有加载 Vue 和 Element Plus，会自动降级到原生 HTML 按钮
- 所有组件都可以通过工厂方法创建：NHAIObjectFactory.createVueButton()
