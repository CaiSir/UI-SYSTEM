# NHAI UI Vue - 性能测试示例

## 📋 测试文件说明

### 1. performance-test-inline.html ✅ 推荐
- **用途**：内联版本的性能测试，无需服务器即可运行
- **使用方法**：直接在浏览器中打开
- **特点**：使用原生 DOM 创建按钮，测试基础渲染性能
- **测试场景**：10000 个按钮的渲染性能

### 2. performance-test-buttons.html
- **用途**：使用 VueButtonCommand 的完整组件测试
- **使用方法**：需要在 Vite 开发服务器中运行
- **特点**：测试真实的 Vue 组件渲染性能
- **测试场景**：10000 个 Vue 按钮组件的渲染性能

### 3. performance-test-summary.html
- **用途**：测试总览页面
- **用途**：介绍各个测试的用途和使用方法

## 🚀 快速开始

### 方法 1：直接打开（推荐）
```bash
# 直接打开内联版本
open examples/performance-test-inline.html
```

### 方法 2：使用开发服务器
```bash
# 启动 Vite 开发服务器
npm run dev

# 访问测试页面
# http://localhost:5173/examples/performance-test-inline.html
```

## 📊 测试指标

### 性能指标
1. **渲染时间**：从开始创建到完全渲染的时间（毫秒）
2. **DOM 节点数**：生成的 DOM 节点总数
3. **内存占用**：浏览器内存使用情况（MB）
4. **重绘次数**：浏览器重绘的次数

### 预期性能

| 组件数量 | 预计渲染时间 | 内存占用 | DOM 节点 |
|---------|------------|---------|---------|
| 1,000   | < 200ms    | < 10MB  | ~5K     |
| 10,000  | < 2s       | < 50MB  | ~50K    |
| 50,000  | < 10s      | < 200MB | ~250K   |

## 🎯 测试步骤

1. **准备环境**
   - 使用 Chrome/Edge 浏览器（支持内存监控）
   - 打开 DevTools

2. **运行测试**
   - 点击"运行测试"按钮
   - 等待渲染完成
   - 查看统计信息

3. **分析结果**
   - 查看渲染时间是否符合预期
   - 检查内存占用是否正常
   - 使用 Performance 面板分析详细数据

## 🔍 调试技巧

### Chrome DevTools
1. **Performance 面板**
   - 录制性能分析
   - 查看 FPS、CPU 使用率
   - 分析阻塞时间

2. **Memory 面板**
   - 拍摄堆快照
   - 对比前后内存变化
   - 查找内存泄漏

3. **Console**
   - 查看详细日志
   - 监控内存使用

## 📝 注意事项

- ⚠️ 大量组件可能导致浏览器卡顿
- ⚠️ 建议在最新版本的 Chrome 中测试
- ⚠️ 性能测试结果仅供参考，实际性能因环境而异
