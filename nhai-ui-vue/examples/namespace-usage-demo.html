NHAI UI Vue - 命名空间使用示例

💡 命名空间优势

  • ✅ 代码组织清晰：按功能分类（Components、Layout、Navigation）
  • ✅ 避免命名冲突：组件名称更简洁（Button 而不是 NhaiButtonCommand）
  • ✅ 易于使用：通过命名空间快速找到所需组件
  • ✅ 向后兼容：仍然支持平铺导入方式

示例 1: 基础组件命名空间

const { NHAIUIVue } = window.NHAIUIVue
const button = new NHAIUIVue.Components.Button('按钮')
button.setType('primary')

示例 2: 布局组件命名空间

const row = new NHAIUIVue.Layout.Row()
const col = new NHAIUIVue.Layout.Col({ span: 12 })
row.setGutter(16)

示例 3: 导航组件命名空间

const breadcrumb = new NHAIUIVue.Navigation.Breadcrumb([...])
const tabs = new NHAIUIVue.Navigation.Tabs([...])

示例 4: 完整布局示例（命名空间）

const row = new NHAIUIVue.Layout.Row()
const col1 = new NHAIUIVue.Layout.Col({ span: 8 })
const col2 = new NHAIUIVue.Layout.Col({ span: 8 })
const btn1 = new NHAIUIVue.Components.Button('按钮 1')
const btn2 = new NHAIUIVue.Components.Button('按钮 2')
