NHAI UI Vue - 自定义布局示例

通过命令式 API 动态组合组件创建布局

1. 垂直布局（VBox）

const vbox = new VueLayoutBuilderCommand('vbox') vbox.setSpacing(2) vbox.setPadding('20px') const btn1 = new VueButtonCommand('提交') btn1.setType('primary') vbox.addWidget('btn1', btn1) const input = new VueInputCommand('用户名') vbox.addWidget('input', input) element.appendChild(vbox.render())

2. 水平工具栏

const toolbar = new VueLayoutBuilderCommand('hbox') toolbar.setDirection('row') toolbar.setGap('12px') toolbar.setPadding('12px') toolbar.setBackgroundColor('#f5f5f5') const saveBtn = new VueButtonCommand('保存') saveBtn.setType('primary') toolbar.addWidget('save', saveBtn) const cancelBtn = new VueButtonCommand('取消') toolbar.addWidget('cancel', cancelBtn) element.appendChild(toolbar.render())

3. 网格布局

const grid = new VueLayoutBuilderCommand('grid') grid.setSpacing(3) grid.setGap('16px') for (let i = 1; i <= 6; i++) { const card = new VueCardCommand(`卡片${i}`, `内容${i}`) grid.addWidget(`card${i}`, card) } element.appendChild(grid.render())

4. 嵌套布局

// 外层垂直布局 const outer = new VueLayoutBuilderCommand('vbox') outer.setSpacing(2) // 内层水平布局 const inner = new VueLayoutBuilderCommand('hbox') inner.setDirection('row') const btn1 = new VueButtonCommand('按钮1') inner.addWidget('btn1', btn1) const btn2 = new VueButtonCommand('按钮2') inner.addWidget('btn2', btn2) outer.addWidget('inner', inner) element.appendChild(outer.render())
