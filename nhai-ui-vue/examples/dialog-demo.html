NHAI UI Vue - Dialog 组件示例

通过命令式 API 使用 Dialog 组件的各种示例

1. 基础对话框

const dialog = new NhaiDialogCommand('提示', '这是一个基础对话框') dialog.setModelValue(true) dialog.render() document.body.appendChild(dialog.getElement())

2. 带确认和取消按钮的对话框

const dialog = new NhaiDialogCommand('确认', '确定要执行此操作吗？') dialog.setShowFooter(true) dialog.setModelValue(true) dialog.on('confirm', () => { alert('用户点击了确认') }) dialog.on('cancel', () => { alert('用户点击了取消') }) dialog.render() document.body.appendChild(dialog.getElement())

3. 可拖动的对话框

const dialog = new NhaiDialogCommand('可拖动对话框', '这个对话框可以拖动位置') dialog.setDraggable(true) dialog.setModelValue(true) dialog.render() document.body.appendChild(dialog.getElement())

4. 全屏对话框

const dialog = new NhaiDialogCommand('全屏对话框', '这是一个全屏对话框') dialog.setFullscreen(true) dialog.setModelValue(true) dialog.render() document.body.appendChild(dialog.getElement())

5. 自定义宽度对话框

const dialog = new NhaiDialogCommand('自定义宽度', '这个对话框宽度为 70%') dialog.setWidth('70%') dialog.setModelValue(true) dialog.render() document.body.appendChild(dialog.getElement())

6. HTML 内容对话框

const dialog = new NhaiDialogCommand('HTML 内容', '<div style="color: red;">这是红色文字</div><br>这是普通文字') dialog.setModelValue(true) dialog.render() document.body.appendChild(dialog.getElement())

7. 事件监听示例

const dialog = new NhaiDialogCommand('事件示例', '这个对话框会触发各种事件') dialog.setModelValue(true) dialog.on('open', () => console.log('对话框打开')) dialog.on('opened', () => console.log('对话框完全打开')) dialog.on('close', () => console.log('对话框关闭')) dialog.on('closed', () => console.log('对话框完全关闭')) dialog.render() document.body.appendChild(dialog.getElement())

8. 模态样式自定义

// 深色遮罩层 dialog.setModalStyle({ backgroundColor: 'rgba(0, 0, 0, 0.8)' }) // 彩色遮罩层 dialog.setModalStyle({ backgroundColor: 'rgba(64, 158, 255, 0.5)' }) // 透明遮罩层 dialog.setModalBackdrop(false)

9. Dialog 中添加子控件

// 创建对话框 const dialog = new NhaiDialogCommand('表单', '') dialog.setWidth('500px') dialog.setModelValue(true) dialog.setAppendToBody(true) // 渲染对话框 dialog.render() // 添加子控件 - 输入框 const input = new NhaiInputCommand() input.setPlaceholder('请输入用户名') input.setStyle({ marginBottom: '10px', width: '100%' }) dialog.addChild(input) // 添加子控件 - 按钮 const button = new NhaiButtonCommand('提交') button.setStyle({ marginLeft: '10px' }) dialog.addChild(button) dialog.on('closed', () => dialog.unmount())
